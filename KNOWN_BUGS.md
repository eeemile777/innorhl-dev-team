## How to Use This File

**Before starting work**: Grep this file for the area you're about to touch. If the bug is already logged, don't re-investigate from scratch — read the existing entry.

**When you find a new bug**: Add it to `## Open` even if you're not fixing it right now. Takes 2 minutes, saves 30 minutes for whoever fixes it.

**When a bug is fixed**: Move it from `## Open` to `## Resolved` with the fix summary and the commit hash.

**When a bug is not our problem**: Move to `## Won't Fix` with the reason.
